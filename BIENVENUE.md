# Bienvenue dans Creator Skills

Tu parles à Claude dans le chat. Tes 5 agents font le reste. Rien n'est envoyé, publié ou payé sans ton OK.

**Par où commencer (dans cet ordre)**
1. « Bienvenue » : 3 minutes de questions pour que Claude te connaisse.
2. **Le Stratège** : « Positionne-moi », puis « Fais mon calendrier de contenu ».
3. **Le Scripteur** : « Écris les scripts de la semaine ». Ou tire 5 cartes : « J'ai tiré H06, F01, C01, E02, CTA01, sujet : [ton sujet] ».
4. **Le Monteur** : glisse ta vidéo + « Monte cette vidéo ».
5. **Le Carrousel** : « Fais-moi un carrousel sur [ton sujet] ».
6. **Le Publieur** : « Programme ma semaine ».

**Ton guide** : chaque agent, la phrase à dire, ce que ça donne. Il est dans Documents/Brain/GUIDE.html. À tout moment : « Montre-moi le guide ».
